# Spring Boot - Basics

This repository contains my first experience with the Spring Boot framework, focusing on its fundamentals and best practices.

Although this was my first experience with Spring Boot, I did not find the implementation of some of its concepts particularly difficult. I know the project is not very complex, but my previous experience with FastAPI during a hackathon I participated in helped me a lot in understanding the fundamentals of RESTful APIs.

Besides that, I really enjoyed revisiting some of the concepts I learned in my Object-Oriented Programming course at university. It was interesting to see how those concepts connect with backend development using Spring Boot. ## Technologies & Concepts
- REST API — API design using HTTP methods and endpoints
- Spring Boot — Framework for building the REST API
- Java — Main programming language
- Maven — Dependency management and project build
- PostgreSQL — Relational database
- Docker & Docker Compose — Containerization and database setup
- Spring Data JPA — Database access and persistence
- JpaRepository — Repository abstraction for interacting with the database
- DTOs — Separation between API requests/responses and database entities
- Bean Validation — Request data validation using Jakarta Validation
- Service Layer — Separation of business logic from controllers
- Exception Handling — Handling errors and invalid requests
